# Portfolio SQL — Análisis de Datos

Repositorio con ejercicios de análisis de datos resueltos en SQL, orientados a preguntas de negocio reales (no solo sintaxis). Cada ejercicio incluye las queries y una conclusión en lenguaje de negocio, pensada para lo que necesitaría leer un manager o un equipo de dirección, no un desarrollador.

## Sobre mí

Aspirante a Data Analyst, actualmente construyendo portfolio en SQL, limpieza y preparación de datos, y Power BI. Este repositorio recoge ejercicios prácticos resueltos de forma autónoma para demostrar razonamiento analítico de principio a fin: desde la query hasta la recomendación.

## Contenido

| Carpeta | Tema | Técnicas destacadas |
|---|---|---|
| [`ejercicio-1-retail/`](./ejercicio-1-retail) | Ventas, márgenes y productos de una cadena retail | JOINs, agregaciones, CTEs, funciones de ventana (`RANK`) |
| [`ejercicio-2-clientes/`](./ejercicio-2-clientes) | Comportamiento y retención de clientes | Subqueries, `NOT EXISTS`, `LAG`, análisis de cohortes/churn |
| [`ejercicio-3-rendimiento/`](./ejercicio-3-rendimiento) | Evolución interanual de tiendas (ventas vs. margen) | CTEs anidadas, pivoteo con `CASE`, análisis de cuadrantes |

## Enfoque

En los tres ejercicios se sigue el mismo criterio: escribir SQL correcto es el punto de partida, no el objetivo final. Cada proyecto termina con una traducción de los resultados a una recomendación accionable, priorizando qué haría un equipo de negocio con esa información.
