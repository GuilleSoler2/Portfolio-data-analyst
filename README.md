Portfolio Data Analyst

Repositorio con ejercicios de análisis y preparación de datos, orientados a preguntas de negocio reales, no solo a la sintaxis técnica. Cada proyecto incluye el trabajo técnico (queries o limpieza) y una conclusión en lenguaje de negocio, pensada para lo que necesitaría leer un manager o un equipo de dirección.

Sobre mí

Aspirante a Data Analyst, actualmente construyendo portfolio en SQL, limpieza y preparación de datos, y Power BI. Este repositorio recoge ejercicios prácticos resueltos de forma autónoma para demostrar razonamiento analítico de principio a fin: desde el dato crudo hasta la recomendación.

Enfoque

En todos los ejercicios se sigue el mismo criterio: la parte técnica (SQL correcto, una limpieza bien hecha) es el punto de partida, no el objetivo final. Cada proyecto termina con una traducción de los resultados a una recomendación accionable, priorizando qué haría un equipo de negocio con esa información — y, en los ejercicios de limpieza, con un principio explícito de no eliminar ni inventar datos sin dejarlo documentado y trazable.
